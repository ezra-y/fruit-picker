# 金枕 / Monthong 挑选指南

**品种范围：** 只针对 **Monthong / 金枕**。刺尖和果壳色值不得套到猫山王、D24、干尧、黑刺或未知品种。

目标是从一颗或多颗金枕中判断成熟窗口、风险和肉量外观，计算购买指数并选出更值得买的候选。照片不齐时先给能成立的局部判断，再只补最影响排序的信息。

光源、证据质量 `Q`、置信度、合并提问与输出增强的通用协议见 [../common.md](../common.md)；本文只列金枕特有的档位映射与差异规则。

## 0. 输入策略、最低照片与系数

完成一颗整果购买评估的最低照片：

1. 整果图：完整轮廓和多房起伏。
2. 果身中段、果房鼓包中部的刺尖及果壳近照。
3. 果柄和连接处近照。
4. 底部及所有开口、裂口、异常处近照；裂口正反面都要看清。

四图清单示意：[../anchors/howto-durian-monthong-4-photos.jpg](../anchors/howto-durian-monthong-4-photos.jpg)。

输入分工：

- `【Agent 读取】`：照片中的 `M1-M5`、风险安全、`Y1-Y7`，并给每条实际使用的证据记录统一证据质量 `Q`。
- `【问用户】`：未说明食用时间时补问食用时间 `U`：“A 今天/马上吃；B 买回短期后熟；C 不确定。”
- `【问用户】`：照片里有多颗或用户要求比较时，记录选择模式 `P`：“A 判断单颗；B 多颗排序。”多颗排序仍必须取得 `U`。
- `【问用户】`：准备使用照片颜色 `M1/M2` 时，按 [../common.md](../common.md) 光源协议取得 `G`；金枕取数值：可用 `1.0`、弱用 `0.5`、停用 `0`（不填 `M1/M2`）。
- `【条件补问】`：照片成熟度无法稳定定档、跨过关键档位或用户明确问今天能否吃时，再问气味 `M6` 和捏刺/轻晃 `M7`。

### 0.1 色值不可用时的文字兜底

色值不可用时可做不进公式的文字兜底：整体仍鲜绿、亮绿且房线、沟槽、果柄也偏早，可提示“偏早倾向”；整体转绿褐或黄褐，且至少两个非颜色成熟项同向，可提示“有成熟倾向”。不能仅凭肉眼颜色给购买指数加分。

### 0.2 输入质量：统一证据质量 `Q`

`Q` 三档定义与有效状态值收缩公式见 [../common.md](../common.md)；照片观察和用户操作每条证据分别记录，直接改变该项有效状态值，不只改变旁路置信度。

风险不套公式：确认“干净”时取底部、果柄、壳面和全部裂口证据中最低的 `Q`；疑似硬风险但细节不清时，补异常处特写或直接换候选。

## 1. 成熟度与食用窗口取值

成熟度先判断采收成熟倾向和是否接近目标食用窗口，不能直接等同今天适吃。先用 `M1-M5` 初算；判断不稳时再补 `M6/M7`。

### 1.1 `M1` 刺尖颜色（权重：`11`）

只在确认金枕、`G > 0`、刺尖近照清楚且系统实际完成校准 CIELAB/Hue 计算时使用。校准计算由本 skill 的 `scripts/color_lab.py` 执行（白平衡校正 → sRGB→XYZ(D65)→L\*a\*b\*→Hue，输出档位与拒填标志）。不能凭肉眼估算，也不是手机 RGB/Hex 阈值。

取果身中段、果房鼓包中部多个相邻刺尖，最好覆盖两个以上果房区域。头尾、果柄附近、沟槽深处、开口边缘、阴影、反光、污渍和湿亮处不用。

| 阶段 | L* | b* | Hue | `M1` |
|---|---:|---:|---:|---:|
| 明显偏早 | `>= 35` | `<= 19` | `<= 67` | `15-35` |
| 过渡 | `> 32.5` 且 `< 35` | `> 19` 且 `< 21.5` | `> 67` 且 `< 72` | `45-65` |
| 成熟倾向 | `29-32.5` | `21.5-23` | `72-79` | `75-95` |

三个轴必须同时落入同一阶段。方向冲突、落在空档或只支持一两个轴时不填。`L* <= 32.5` 且 `b* < 21` 先排查暗光/污渍；`b* >= 21` 且 `Hue < 72` 不填；`L* >= 35` 且 `b* >= 21` 先排查黄光；`a*` 不参与判断。

### 1.2 `M2` 果壳颜色（不进入普通手机购买分）

`M1/M2` 来自相关颜色变化，不能在普通手机条件下重复计分。`M2` 只作实验交叉检查和文字说明；成熟公式只保留取样位置更明确的 `M1`，且其权重限制为 `11`。果壳区间由本 skill 的 `scripts/color_lab.py --surface shell` 实现并执行。果壳支持但刺尖或多个非颜色项反向时，不能直接给高成熟结论。

### 1.3 `M3` 房线 / 纵向果房轨迹（权重：`15`）

弱与清楚的对比：[../anchors/anchor-monthong-seam-lines.jpg](../anchors/anchor-monthong-seam-lines.jpg)。

| 照片表现 | `M3` |
|---|---:|
| 房线弱，果身显得紧 | `30-45` |
| 房线隐约可见但不连续，介于两档之间 | `45-60` |
| 房线清楚，能看到一瓣一瓣的纵向走向 | `70-90` |
| 房线处开裂、湿黏、发黑或发霉 | 不填，进入风险 |

### 1.4 `M4` 果柄成熟形态（权重：`22`）

三档对比：[../anchors/anchor-monthong-stem-grades.jpg](../anchors/anchor-monthong-stem-grades.jpg)。

| 照片表现 | `M4` |
|---|---:|
| 颜色较深、表面粗糙、连接处有膨大感 | `70-90` |
| 完整干净，但成熟形态不明显 | `45-60` |
| 明显干缩、枯皱、细小 | `25-45` |
| 发黑、湿黏、发霉或腐烂 | 不填，进入风险 |

### 1.5 `M5` 刺间沟槽（权重：`7`）

紧与开的对比：[../anchors/anchor-monthong-grooves.jpg](../anchors/anchor-monthong-grooves.jpg)。

| 照片表现 | `M5` |
|---|---:|
| 沟槽紧、挤、间距不明显 | `30-45` |
| 沟槽中等，介于紧与开之间 | `45-60` |
| 沟槽更宽、更开、更明显 | `70-90` |
| 局部或大面积发黑、湿、斑块状 | 不填，进入风险 |

### 1.6 `【条件补问】` `M6` 气味（权重：`11`）

只有用户确认闻的是这颗果，且摊位混味、冷藏、包膜等干扰不重时使用。

问：“只闻这颗榴莲的果柄和房线附近，是无味、青草味、淡甜榴莲香、特别刺鼻，还是酸味/酒精味？”（闻的位置示意：[../anchors/howto-durian-monthong-M6-smell.jpg](../anchors/howto-durian-monthong-M6-smell.jpg)）

| 用户描述 | `M6` |
|---|---:|
| 无味 | `35-50` |
| 青草味 | `15-35` |
| 淡淡甜香 / 正常榴莲香 | `70-90` |
| 特别刺鼻浓香 | `55-70`，必须结合触感和风险 |
| 酒精味 / 酸味 | 不填，硬风险 |

### 1.7 `【条件补问】` `M7` 捏刺 / 轻晃（权重：`34`）

避开裂口和软塌处，轻捏果身中段相邻两根刺；拿取安全时再轻晃。不要要求用户用力按壳。（捏刺手位：[../anchors/howto-durian-monthong-M7-pinch.jpg](../anchors/howto-durian-monthong-M7-pinch.jpg)；轻晃姿势：[../anchors/howto-durian-monthong-M7-shake.jpg](../anchors/howto-durian-monthong-M7-shake.jpg)）

| 用户描述 | `M7` |
|---|---:|
| 相邻刺完全捏不动 | `15-35` |
| 相邻刺稍能靠近 | `70-90` |
| 相邻刺异常软塌，或壳面按下塌陷 | 不填，硬风险 |
| 轻晃有轻微壳肉分离感 | `65-85` |
| 完全没有分离感 | `35-50` |

只完成一个动作时按该动作取值；两个动作同向时取两个区间的交集。方向冲突时不填 `M7`，不能保留高分后只降低 `Q`。

## 2. 风险安全取值

风险按最严重状态定档，不做平均。关键安全部位看不清时不计算购买指数。

开口尺寸使用照片内的相对参照，不要求用户拿尺：

- **缝隙宽度**：用开口旁同一平面的一根相邻刺底宽度作参照；只量两侧壳缘之间最宽处，不把阴影算进缝隙。
- **开口长度**：用同一条房线上从底部到肩部的可见房线长度作参照；照片没有拍全这条房线时，长度档不填。但已明确超过某档下限的绝对判据（如长度超过 `2` 个相邻刺间距）仍然成立，可先给「至少某档」的下界结论，再补图定上界。
- **颜色**：只看裂口边缘本身。浅白或浅米色是新鲜壳内边缘；黄褐、深褐、黑色或灰暗干缩按旧裂处理。暖黄灯且没有白灰参照时，不判断边缘颜色。

| 风险状态 | 可执行定义 | 购买处理 |
|---|---|---|
| 硬风险 | 果肉可见；或任意开口发霉、湿黏、流液、有虫蚁；或果柄黑软腐烂、水浸状深斑、深破损、异常软塌、明确酸味/酒精味/污染 | 硬风险直接不买，不计算购买指数 |
| 风险开口 | 任一成立：开口长度 `>=` 可见房线长度的 `1/3`；最宽缝隙 `>= 1` 个相邻刺底宽度；两条以上房线同时开裂；边缘黄褐/深褐/黑或明显干缩。未露肉也按此档 | 风险开口：最终建议固定为不建议买 |
| 中等开口 | 单条房线开口；长度大于 `2` 个相邻刺间距但 `< 1/3` 可见房线；或最宽缝隙大于 `1/4` 且 `< 1` 个相邻刺底宽度；可连续看到浅白/浅米色内壳边缘；未露肉、未湿黏、未霉、未虫蚁 | 中等开口：最终建议最高为限定条件可买；仅限当天处理、接受短货架且商家包赔 |
| 小开口 | 单条房线、单一连续细缝；长度 `<= 2` 个相邻刺间距；最宽缝隙 `<= 1/4` 个相邻刺底宽度；只能看到细线状浅色边缘或看不到连续内壳；未露肉、未湿黏、未霉、未虫蚁 | 小开口：最终建议最高为限定条件可买；同等条件优先无开口 |
| 无开口且关键部位干净 | 房线闭合；果柄完整；壳面和沟槽无湿黏、霉、腐烂、水浸状深斑 | 允许进入目标匹配和肉量外观评分 |
| 关键部位看不清 | 底部、果柄、裂口背面或异常处缺图；不能确认尺寸参照或边缘状态 | 不填 |

长度和宽度落入不同档时取更严重档；边缘旧、湿、霉、虫或露肉也取更严重档。开口本身不证明成熟。定档拿不准时对照四档对比图：[../anchors/anchor-monthong-opening-grades.jpg](../anchors/anchor-monthong-opening-grades.jpg)（AI 示意，只看相对严重程度）。

## 3. 肉量外观取值

肉量外观只比较外观看起来的果房充实程度，不判断甜、熟、干包/湿包，也不估具体出肉率。

### 3.1 `Y1` 果包饱满度（权重：`33`）

饱满与瘪塌的对比：[../anchors/anchor-monthong-bulge-fullness.jpg](../anchors/anchor-monthong-bulge-fullness.jpg)。

| 表现 | `Y1` |
|---|---:|
| 多个果房隆起清楚，每房从上到下较饱满 | `80-100` |
| 部分果房饱满，但不连续 | `60-80` |
| 整体中等，无明显优势或缺陷 | `45-60` |
| 多处扁、塌、凹、窄，或整体瘪 | `15-40` |

### 3.2 `Y2` 果房连续性（权重：`33`）

| 表现 | `Y2` |
|---|---:|
| 可见多房且包型连续 | `80-100` |
| 可见约三房，连续性一般 | `60-80` |
| 房数少、房小、壳间隔占空间多 | `25-50` |
| 只拍到局部 | 不填 |

### 3.3 `Y3` 局部空瘪 / 塌陷（权重：`14`）

| 表现 | `Y3` |
|---|---:|
| 未见明确局部塌陷 | `80-100` |
| 轻微局部不饱满或凹窄 | `50-70` |
| 某一房明显扁、塌、凹、窄 | `15-40` |

### 3.4 `Y4` 整体果形（权重：`5`）

| 表现 | `Y4` |
|---|---:|
| 多房分布基本均衡、整体圆鼓 | `75-90` |
| 中等，无明显优势或缺陷 | `45-60` |
| 严重畸形、左右明显不均 | `20-40` |

### 3.5 `Y5` 刺形线索（权重：`7`）

只看果身中段、果房鼓包中部；刺形只能辅助肉量外观，不能单独判断壳厚或出肉率。四类刺形对比：[../anchors/anchor-monthong-spine-shapes.jpg](../anchors/anchor-monthong-spine-shapes.jpg)。

| 表现 | `Y5` |
|---|---:|
| 奶油长尖：底座窄，刺身细长，像奶油拉尖般顺滑收尖，末端可轻微弯钩；同时果房鼓包饱满、刺距略开但不孤立 | `65-80` |
| 粗底短尖：底座粗壮敦实，刺尖短钝，但果房仍鼓包、刺不贴壳 | `55-70` |
| 刺形中等，或刺距、刺形、果包互相冲突 | `45-60` |
| 矮沙丘刺：果房中部的刺矮、扁、贴壳、突起不高，像趴在壳上的小沙丘 | `20-40` |
| 金字塔刺：底座宽、整体呈三角塔状；细直尖：又细又直、常见于头尾两端 | 不在核心观察区时不填 |
| 只看到刺密或刺疏，看不清果房位置和果包 | 不填 |

### 3.6 `Y6` 尾部（权重：`4`）

| 表现 | `Y6` |
|---|---:|
| 尾部无明显凹陷，整体配合果包饱满 | `70-90` |
| 尾部明显凹进去，或某侧塌陷 | `25-45` |
| 尾部过尖、过长，且果包不饱满 | `25-45` |
| 只凭圆尾或尖尾一个特征 | 不填 |

### 3.7 `Y7` 果柄粗壮辅助（权重：`4`）

| 表现 | `Y7` |
|---|---:|
| 粗壮、干净、未霉、未腐 | `70-90` |
| 中等，看不出明显优势 | `45-60` |
| 明显干缩、枯皱、细小 | `25-45` |

同一局部缺陷不能重复扣分：果房局部扁塌优先记 `Y3`；整体左右失衡或多房畸形记 `Y4`；只发生在尾部才记 `Y6`。已经记入 `Y3` 的单一局部塌陷，不再同时下调 `Y1/Y2`；只有它独立影响多个果房的整体饱满度或连续性时，才可另记 `Y1` 或 `Y2`。

## 4. 公式与购买建议

所有路由使用固定 `100` 权重。适用但没有可靠观察到的弱项以 `Q=0` 回到中性 `50`；核心项缺失时不计算完整分数。变量是区间时分别计算上下限，购买结论按下限落档。

### 4.1 成熟度区间

```text
成熟度区间 =
11% × M1有效值
+ 15% × M3有效值
+ 22% × M4有效值
+ 7% × M5有效值
+ 11% × M6有效值
+ 34% × M7有效值
```

`M2` 不进入公式。`M1` 的有效 `Q` 取输入质量与 `G` 中较低者；`M6/M7` 的含糊回答会直接向 `50` 收缩，不能用完整权重推过档位。

| 成熟度区间 | 基础输出 |
|---:|---|
| `>= 70` | 成熟倾向；仍不直接等同今天适吃 |
| `55-69` | 接近成熟，结合 `U` 和触感 |
| `40-54` | 不确定 |
| `< 40` | 偏生风险 |

照片信号跨过 `55/70`、互相冲突或用户明确问今天能否吃时，再补 `M6/M7`。

成熟度核心证据门槛：至少有 `M1` 或 `M7` 一项 `Q>=0.5`，并再有一个独立成熟信号可用。今天/马上吃必须有 `M7` 的可用触感；只有 `M1` 颜色或只有 `M3-M5` 时，只报采收成熟倾向，不计算今天适吃购买分。

### 4.2 肉量外观区间

```text
肉量外观区间 =
33% × Y1有效值
+ 33% × Y2有效值
+ 14% × Y3有效值
+ 5% × Y4有效值
+ 7% × Y5有效值
+ 4% × Y6有效值
+ 4% × Y7有效值
```

| 肉量外观区间 | 输出 |
|---:|---|
| `>= 70` | 较好 |
| `50-69` | 一般 |
| `< 50` | 有风险 |
| `Y1/Y2` 都不填 | 无法判断；辅助项不能单独给“较好” |

`Y1/Y2/Y3` 共用果房充实组 `80` 的预算，`Y4/Y6` 共用轮廓组 `9`，`Y5/Y7` 为辅助组 `11`。同一塌陷仍只记录一项。计算购买指数前，`Y1/Y2` 必须都能填写，且至少一项 `Q=1`、另一项 `Q>=0.5`；两项都只有 `Q=0.5` 或任一缺失时只报局部肉量外观，不让刺形或尾部辅助生成高推荐。

### 4.3 购买指数与多颗排序

购买指数只适用于第 2 节“无开口且关键部位干净”档。任何开口、硬风险或关键安全部位看不清，都直接使用第 2 节结论，不生成分数。「不生成分数」只指购买指数：成熟度区间和肉量外观区间在各自证据门槛满足时照常计算并输出（见 output-guide 第 8 节示例）。

```text
购买指数区间 =
70% × 成熟窗口匹配值
+ 30% × 肉量外观区间
```

旧公式去掉风险后，将原成熟与肉量的 `45:20` 相对关系取整为 `70:30`。风险是购买资格，不再用近似常量参与排序。

| `U` | 成熟度状态 | 成熟窗口匹配值 |
|---|---|---:|
| A 今天/马上吃 | `70-84` 且 `M7` 不反向 | `100` |
| A 今天/马上吃 | `>= 85` 且无风险 | `75`，货架余量较短 |
| A 今天/马上吃 | `55-69` | `50` |
| A 今天/马上吃 | `40-54` | `25` |
| A 今天/马上吃 | `< 40` | `0` |
| B 买回短期后熟 | `55-69` | `100` |
| B 买回短期后熟 | `70-84` | `75` |
| B 买回短期后熟 | `40-54` | `50`，后熟能否到位未确认 |
| B 买回短期后熟 | `>= 85` | `25`，短期余量有限 |
| B 买回短期后熟 | `< 40` | `25` |
| C 不确定 | 直接使用成熟度区间 | 原成熟度值 |

气味特别刺鼻、触感明显偏软、开口扩大或其他高熟风险先回到第 2 节，不用窗口分洗白。

| 购买指数区间 | 建议 |
|---:|---|
| `>= 75` | 建议买 |
| `60-74` | 限定条件可买；说明当天吃或后熟条件 |
| `45-59` | 补图、开果确认或换一颗 |
| `< 45` | 不建议买 |

购买结论按区间下限对应档位输出。

多颗比较时必须先给每颗候选编号，确保整果、果柄、底部和特写属于同一颗。开口果先按第 2 节购买上限排序；无开口干净果只有在核心成熟证据和肉量照片覆盖相近时才比较购买指数下限。覆盖差异明显时先补相同部位；区间重叠时依次比较目标窗口、肉量外观和输入质量，仍无法拉开则明确并列。

## 5. 输出口径

必须给用户一个明确购买结论，不能只罗列观察项。满足第 4.3 节门槛时才给推荐指数；开口、硬风险或信息不足时直接写“不计算指数：原因”，不把它说成缺失信息。甜度、干包/湿包、出肉率这些开果前看不到的事，别打包票。

```text
结论：
- 购买建议：建议买 / 限定条件可买 / 补图或开果确认 / 不建议买 / 直接不买
- 推荐指数：购买指数区间，或“不计算指数：开口 / 硬风险 / 信息不足”
- 成熟度与目标窗口：分数区间 + 偏生 / 不确定 / 接近可吃 / 适吃倾向
- 风险：无开口干净 / 小开口 / 中等开口 / 风险开口 / 硬风险 / 看不清，并指出决定结论的部位
- 肉量外观：分数区间 + 较好 / 一般 / 有风险 / 无法判断
- 置信度：高 / 中 / 低；说明限制来自输入质量、覆盖度、规则适用性或信号冲突
- 多颗排序：从最值得买到最不值得买，并说明拉开差距的主要变量
- 最少补充：只要求当前最可能改变购买结论或排序的一项
```

只有 `M3-M5` 或只有刺形、尾部、果柄辅助时，规则适用性最高为低到中。肉量外观即使核心项清楚同向，置信度最高仍为中；它不是开果后的出肉率验证。
