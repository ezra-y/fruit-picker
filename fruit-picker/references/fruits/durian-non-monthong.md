# 非金枕：猫山王 / D24 / 黑刺 挑选指南

**适用范围：** 用户选择或标签显示为猫山王 D197、D24/Sultan、黑刺 D200。  
**不适用：** 金枕 / Monthong；金枕必须读 `durian-monthong.md`。  
**当前状态：** 低置信参考。只做身份辅助、外部风险和开果验货；未开整果不能高置信判断成熟或好吃。

## 0. 输入策略与开果状态路由

光源、证据质量 `Q`、置信度、合并提问与输出增强的通用协议见 [../common.md](../common.md)；本文只列非金枕品种特有的路由与差异规则。

最低必要输入按能力区分：

- **只做风险检查：** 开果状态和清楚的风险照片/描述即可；风险检查不要求品种。
- **做身份一致性或品种画像：** 用户声称的品种/清楚标签 + 开果状态：**未开整果 / 已开果 / 盒装**。

输入分工如下。只有标记为 `【问用户】` 或 `【条件补问】` 的项目才向用户发问。

- `【Agent 读取】`：从照片读取开果状态、标签、形状/纹路身份线索和非颜色风险。未开整果优先看整果、底部、果柄和全部裂口；已开/盒装优先看果肉形态、芯部、房内壁和异常质地。
- `【问用户】`：要做身份一致性或品种画像，但照片/消息没有明确品种或开果状态时，问：“标签写的是什么品种？这是未开整果、已经开果，还是盒装果肉？”只做风险检查时不强问品种。
- `【问用户】`：只要准备使用壳色、果肉颜色、灰黑/白斑等照片颜色判断，按 [../common.md](../common.md) 光源协议取得 `G`；停用档时不用颜色判断身份、画像或灰黑程度，改用形状、纹路和质地。
- `【条件补问】`：已开/盒装且需要确认风险或口味画像时，才问是否有酸味、酒精味、腐味、淡水味或微苦回甘。已经出现霉、渗水、发黏等硬风险时不要让用户试吃；口感只使用用户已经尝过后的描述。

先按品种路由，再按开果状态决定能力：

底部身份线索对比（星形底 / 硬币秃区 / 凹陷黑点，仅低置信辅助）：[../anchors/anchor-nonmonthong-identity-cues.jpg](../anchors/anchor-nonmonthong-identity-cues.jpg)。

| 品种 | 处理 |
|---|---|
| 金枕 / Monthong | 停止使用本文，改读 `durian-monthong.md` |
| 猫山王 / Musang King / D197 | 进入第 3 节 |
| D24 / Sultan | 进入第 4 节 |
| 黑刺 / Black Thorn / D200 / Ochee / Duri Hitam | 进入第 5 节 |
| 其他品种或品种不明 | 只做第 2 节风险检查，不判断身份或成熟 |

| 开果状态 | 执行路径 |
|---|---|
| 未开整果 | 先查外部风险，再做低置信身份一致性；不判断内部成熟、甜度或干湿包 |
| 已开果 | 先应用共用开果风险，再看对应品种的果肉画像 |
| 盒装 | 与已开果相同，并额外留意冷冻/解冻、白斑、黑芯和渗水 |

已经有标签、开果图或用户描述时不要重复询问。

## 1. 能力与边界

| 输入 | 能判断什么 | 置信度 |
|---|---|---|
| 未开整果 + 品种/标签 | 外观风险、身份是否大致一致、是否需要补图 | 低 |
| 未开整果 + 清楚标签 | 标签和外观是否明显冲突、是否有混名风险 | 低到中 |
| 已开果 / 盒装果肉 | 果肉状态、冷冻/解冻风险、是否符合品种画像 | 中 |
| 用户补充气味/口感 | 酒精味、酸败、微苦回甘、淡水味等风险或偏好 | 中 |

不能：

- 从未开整果照片判断甜度、干包/湿包、死包或内部褐变。
- 把金枕的 L*/b*/Hue、刺尖或果壳区间套过来。
- 把品种识别线索当成熟结论。
- 只靠价格、稀缺性、商家口播、壳色或刺色判断好吃。

## 2. 共用风险协议

### 2.1 未开整果风险

| 风险 | 表现 | 输出 |
|---|---|---|
| 露肉大裂口 | 果肉暴露、裂口污染或虫蚁可进入 | 不建议买；身份线索不能抵消污染风险 |
| 湿黏/渗液 | 壳面、裂口或果柄湿黏、流液 | 不建议购买；停止身份和成熟正向 |
| 霉/腐烂 | 果柄、裂口或壳面霉点、黑软腐烂 | 不建议购买 |
| 小而干净的旧裂 | 未露肉、未湿黏、未霉 | 只提示短货架，不拿裂口证明成熟 |

### 2.2 共用开果风险

已开果和盒装先看本表。任一强风险都压过品种画像。

| 风险 | 表现 | 输出 |
|---|---|---|
| 酸败/酒精味 | 明显酸味、酒精味或腐味 | 不建议食用；停止“是否符合品种”正向 |
| 水泥状/透明水感 | 软塌成泥、渗水、发黏、透明感 | 不建议购买或继续食用；不按奶油质地解释 |
| 灰黑/霉 | 果肉、房内壁或芯部异常灰黑、霉点 | 不建议食用 |
| 白斑/黑芯/硬结 | 尤其冷冻或盒装猫山王 | 质量强风险，建议换货/退货；伴随渗水、发黏或异味时不建议食用 |
| 大面积褐变 | 灰肉、血管状褐变或污染感 | 不建议购买或继续食用；不能靠果肉颜色深浅抵消 |

正常奶油质地与水泥状渗水的对比：[../anchors/anchor-nonmonthong-flesh-risk.jpg](../anchors/anchor-nonmonthong-flesh-risk.jpg)。

## 3. 猫山王 / Musang King / D197

### 3.1 未开整果：只做身份辅助

| 输入 | 支持身份一致性 | 边界 | 输出 |
|---|---|---|---|
| 果体大小 | 官方品种资料约 `1.0-1.8 kg` | **低权重**；市场果可能超出，大小不能单独定品种 | 只作弱背景，不判断成熟 |
| 刺形 | 鼓包处刺偏钝、偏疏，像小蒙古包 | 包装遮挡或拍不清时不用 | 多项同时一致才提高身份置信 |
| 柄颈 | 果柄连接处有凸起感 | 果柄剪短时不可用 | 只辅助身份 |
| 底部星形 | 可见星形分瓣 | 有星不一定真，真果也可能不明显 | 不能单独定猫山王 |
| 果包 | 外观看起来饱满 | 只能提示外观肉量，不能看出内部 | 不判断甜度或成熟 |

输出核心句：这只能做猫山王身份辅助；未开整果不能判断里面熟不熟或好不好吃。

### 3.2 已开果 / 盒装画像

先通过第 2.2 节共用开果风险，再看：

| 输入 | 更符合猫山王画像 | 输出 |
|---|---|---|
| 果肉颜色 | 均匀金黄 | 只说明画像较一致，不把黄色等同于新鲜 |
| 房内壁/芯部 | 刚打开时干净偏白、芯不黑 | 发黑或湿黏回到共用风险 |
| 果核 | 核常偏扁，新鲜果核可偏翠绿 | 只辅助身份和出肉预期 |
| 质地 | 糯软、细腻、无硬结 | 硬结、水泥状或渗水回到共用风险 |
| 味道 | 浓郁、微苦后回甘 | 酸败、酒味或只有淡水味不作正向 |

## 4. D24 / Sultan

### 4.1 未开整果：身份和弱成熟背景

| 输入 | 支持 | 边界 | 输出 |
|---|---|---|---|
| 底部 | 小硬币状平坦区/秃区 | 可能和其他底部形态混淆 | 更像 D24；不判断成熟 |
| 分瓣线/房线 | 房线可见、线条形成 | 角度差时不用 | 只作弱成熟背景，不能保证好吃 |
| 果柄离层 | 连接处可见离层/成熟迹象 | 果柄剪短时不用 | 只作弱辅助 |
| 壳色 | 浅绿或较均匀绿色 | 光源影响大 | 只作身份背景，不输出成熟结论 |
| 裂口 | 小而干净、未露肉 | 大裂、湿黏、霉走第 2.1 节 | 不用裂口证明成熟 |

### 4.2 已开果 / 盒装画像

先通过第 2.2 节共用开果风险，再看：

| 输入 | 更符合 D24 画像 | 输出 |
|---|---|---|
| 果肉颜色 | 淡黄、浅黄 | 颜色只辅助画像 |
| 果肉状态 | 厚实、奶油感、可略干 | 水泥状、酸酒味回到共用风险 |
| 果核 | 核偏大较常见 | 核大可能降低肉率，不等于坏 |

## 5. 黑刺 / Black Thorn / D200

### 5.1 未开整果：先防误认

| 输入 | 支持 | 边界 | 输出 |
|---|---|---|---|
| 名称/标签 | D200、Ochee、Duri Hitam、Black Thorn 对得上 | “越南黑刺”“泰国黑刺”“刺黑”可能是混名 | 标签清楚才进入黑刺判断 |
| 底部 | 凹陷、黑色花柱/小黑点可作线索 | 其他品种也可能有类似点 | 只辅助身份 |
| 刺色 | 不作为支持 | 只因刺黑就说黑刺 | 明确拒绝该判断 |
| 价格 | 异常低可能需要核对身份 | **低权重**；高价也不等于好吃 | 只提示混名风险 |
| 外观组合 | 果柄粗糙、离层膨大、绿转绿褐、刺尖干褐、房线可见、刺基变宽 | 样本小，无稳定阈值/准确率 | 多项同时出现才作弱背景 |

输出核心句：刺黑不能判断 D200 黑刺，需要标签、底部和开果图；未开整果成熟度仍然低置信。

### 5.2 已开果 / 盒装画像

先通过第 2.2 节共用开果风险，再看：

| 输入 | 更符合黑刺画像 | 输出 |
|---|---|---|
| 果肉颜色 | 深黄、橙黄到橙红 | 深色只辅助画像，不抵消灰黑/渗水风险 |
| 果肉状态 | 细腻、纤维少、奶油感、能成形 | 水泥状、酸酒味回到共用风险 |
| 口味 | 浓郁、有甜苦层次 | 只作口味匹配 |
| 出肉预期 | 核和皮成本可能较高 | 不能用价格倒推肉率或好吃 |

## 6. 输出口径

只输出当前状态真正能支持的内容：

```text
结论：
- 品种身份：一致 / 部分一致 / 冲突 / 无法判断
- 当前能力：未开只做身份和外部风险；已开可做果肉验货
- 风险：未见明显风险 / 需谨慎 / 不建议买或吃
- 验货结果：符合品种画像 / 不典型 / 被风险覆盖
- 置信度：高 / 中 / 低，并说明最关键的缺图或缺失信息
```

未开整果的输出不得出现“已经熟透”“一定好吃”“甜度高”或“干包/湿包确定”等结论。
