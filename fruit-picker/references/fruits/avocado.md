# 牛油果挑选指南

**适用范围：** 整颗鲜食牛油果，优先覆盖 Hass / Hass-like 黑皮粗皮、常见绿皮品种、Shepard、Florida / West Indian 大绿果，以及已切开或盒装果肉。
**不适用：** 只靠照片预测油脂香、坚果味、干物质或未切开的内部褐变。

## 0. 输入策略与最低必要输入

牛油果以用户手感为主，照片负责类型、Hass 颜色辅助和可见风险。采收成熟不等于已经能吃；Hass 变黑规则不能套到绿皮品种。

光源、证据质量 `Q`、置信度、合并提问与输出增强的通用协议见 [../common.md](../common.md)；本文只列牛油果特有的档位映射与差异规则。

- **未开整果基础窗口：** 类型 `T` + 手掌轻压 `F`。没有 `F` 时，不能判断今天能不能吃。
- **吃法匹配或多颗比较：** 再取得食用时间/吃法 `U`。
- **已切开/盒装：** 直接读取内部状态 `I`，不要求补手感。
- **完整购买分：** 未开果还必须确认表皮和蒂端风险 `R`；风险关键处看不清时不输出完整购买结论。

输入分工：

- `【Agent 读取】`：从标签和非颜色外观读取类型 `T`、风险 `R`；已切开时读取内部状态 `I`。
- `【问用户】`：未开果必须问手掌轻压 `F`；缺少目标时问食用时间/吃法 `U`。
- `【问用户】`：准备使用照片中的 Hass 颜色 `C` 时，按 [../common.md](../common.md) 光源协议取得 `G`（`usable / weak / disabled / unknown`）。
- `【条件补问】`：疑似冷害或用户问催熟时再问储存背景 `S`；可见湿烂但气味不清时才问是否有酸败/腐味。

每个收集项都有代号，后续用代号组合判断。已经得到的信息不要重复问；用户未实际按压或无法确认时，对应项不填。

## 1. 路由参数

### 1.1 类型 `T`

用户能说出品种时直接映射；不知道时由 Agent 根据标签和整果照片分流。

| `T` | 类型 | 路由 |
|---|---|---|
| A | Hass / Hass-like 黑皮粗皮 | 手感为主，可启用 Hass 颜色辅助 |
| B | Fuerte / Bacon / Reed / Pinkerton / Zutano / Gwen 等绿皮 | 只看手感和风险，不等变黑 |
| C | Florida / West Indian 大绿果 | 只看手感、吃法和风险 |
| D | Shepard / 澳洲绿皮 | 只看手感和风险，不等变黑 |
| E | 已切开或盒装 | 直接进入 `I` |
| F | 不确定 | 要标签或整果图；仍不确定时降低规则适用性 |

### 1.2 `【问用户】` 食用时间/吃法 `U`

```text
你准备什么时候、怎么吃？
A. 今天切片/沙拉/摆盘，要成形
B. 今天直接吃，正常软糯即可
C. 今天做酱、泥或奶昔，要更软
D. 明天或未来几天吃
E. 只是比较哪颗更值得买
F. 不确定
```

`U=E` 没有明确目标，不能计算目标匹配分，先补一个时间或吃法。`U=F` 暂按今天直接吃计算，但置信度最高为低到中。

### 1.3 `【Agent 读取】` Hass 颜色 `C`

光源 `G` 按 [../common.md](../common.md) 协议取得；Hass 颜色可靠度 `Q` 由 `G` 决定（`usable→1`、`weak→0.5`、`disabled/unknown→0` 且不填 `C`）。

只有 `T=A` 且 `G=usable/weak` 时读取黑化面积：

| `C` | 可执行定义 |
|---|---|
| 绿色阶段 | 通体绿色或黑化约 `0-25%` |
| 过渡阶段 | 深绿到紫黑过渡，黑化约 `26-75%` |
| 深色阶段 | 大部分黑化或近黑，黑化 `>75%` |
| unknown | 偏色、反光、遮挡或无法稳定分档 |

Hass 绿色不等于采收不成熟，全黑也不等于状态好；绿皮品种完全不使用这张颜色表。三阶段对比板（仅 `G` 可用时对照）：[../anchors/anchor-avocado-hass-color-stages.jpg](../anchors/anchor-avocado-hass-color-stages.jpg)。

## 2. 加权参数与风险

### 2.1 `【问用户】` 手掌轻压 `F`

让用户用手掌轻握全果，不用指尖戳，不按软斑、破口或蒂端。（正误对比示意：[../anchors/howto-avocado-F-grip.jpg](../anchors/howto-avocado-F-grip.jpg)）

| `F` | 可执行定义 |
|---|---|
| A | 石头硬，完全不让步 |
| B | 偏硬，但有一点让步 |
| C | 全果均匀轻柔让步，会回弹 |
| D | 容易让步但仍成形、不糊不塌 |
| E | 局部或整体糊软、不回弹 |
| F | 没法按/不确定 |

`F=D` 是正常 fully-ripe 软熟档，不自动判过熟。发黏、出水、湿烂、流液或异味不塞进 `F=E`，统一进入风险。

### 2.2 手感 × 吃法状态值

状态值只表示“当前手感是否匹配这次吃法”，不是好吃概率。

| `F` | `U=A` 切片 | `U=B` 直接吃 | `U=C` 酱泥 | `U=D` 未来几天 |
|---|---:|---:|---:|---:|
| A 石头硬 | `0` | `0` | `0` | `75` |
| B 偏硬有一点让步 | `50` | `25` | `25` | `100` |
| C 均匀轻柔让步 | `100` | `100` | `75` | `50` |
| D 容易让步仍成形 | `25` | `75` | `100` | `25` |

`F=E` 不进入加权，先按过熟/碰伤风险处理；`F=F` 为核心输入缺失，不计算。

### 2.3 Hass 颜色辅助状态值

| `C` | 今天切片/直接吃/酱泥 | 未来几天 |
|---|---:|---:|
| 绿色阶段 | `25` | `75` |
| 过渡阶段 | `75` | `75` |
| 深色阶段 | `75` | `25` |

颜色只占 `15`，手感占 `85`。颜色不可用时以 `Q=0` 回到中性 `50`，不会因为删除一个反向颜色项而把分数抬高。

### 2.4 风险 `R/I`

风险状态统一使用 `safe / caution / reject / unknown`，只在这里定义一次。

| 状态 | 表现 | 处理 |
|---|---|---|
| `safe` | 无软烂、霉、流液；只有少量干疤/小斑点 | 可进入评分 |
| `caution` | 局部软斑、凹陷、碰伤、明显皱缩松皮；或疑似冷害 | 优先换一颗；最高只能“匹配但有风险” |
| `reject` | 蒂端黑软腐烂、霉、湿烂、流液、深破口、腐味 | 不建议买/吃，不计算分数 |
| `unknown` | 蒂端、软斑或异常处看不清 | 不输出完整购买结论 |

局部软斑只记入 `R=caution`，不重复塞进手感。小而干燥、无渗液异味时不自动判不可食；扩大、湿烂、发黏或有异味时升级为 `reject`。风险形态对比：[../anchors/anchor-avocado-risk-grades.jpg](../anchors/anchor-avocado-risk-grades.jpg)。

已切开时：黄绿正常为 `I=safe`；少量切面氧化褐边为 `caution`；灰肉、大面积/血管褐变、酸败腐味、水烂、发黏或霉为 `reject`。

储存背景 `S` 只改变处理建议：未熟硬果长期冷藏要提示冷害、内部褐变或后熟异常；纸袋加香蕉/苹果可加速后熟；微波/烤箱只能加热软化，不能补出成熟风味。

## 3. 评分与执行

证据质量 `Q` 三档定义与收缩逻辑见 [../common.md](../common.md)：

```text
有效状态值 = 50 + Q × (状态值 - 50)

Hass 目标匹配分 = 85% × F有效值 + 15% × C有效值
绿皮/大绿果目标匹配分 = F有效值
```

| 分数 | 输出 |
|---:|---|
| `>= 80` | 强匹配当前吃法/时间 |
| `65-79` | 匹配 |
| `50-64` | 临界；优先换更匹配的 |
| `< 50` | 不匹配 |

执行顺序：

1. 先按 `T/U` 选择路由。
2. 检查 `R/I`；`reject/unknown` 不进入完整评分。
3. 未开果取得核心手感 `F`。
4. 只有 Hass 且光源允许时加入 `C`。
5. 按分数给目标匹配结论，再结合风险和规则适用性给置信度。

同一颗有 `R=caution` 时，即使分数很高也不能输出无条件首选。多颗比较必须使用同一个 `U`；先排除风险，再按目标匹配分排序。

## 4. 输出口径

```text
结论：
- 购买建议：优先 / 可买但有条件 / 换更匹配的 / 不建议买
- 可食窗口：今天可用 / 买回后熟 / 不适合今天 / 信息不足
- 吃法匹配：切片成形 / 直接吃 / 酱泥奶昔
- 目标匹配分：满足核心输入时输出（匹配的是手感和吃法）
- 关键依据：类型 + 手掌轻压 + Hass 颜色辅助（仅适用时）
- 风险：表皮、蒂端或内部状态
- 置信度：高 / 中 / 低，并指出最有价值的缺失信息
```

有明确 `T + F + U` 且风险清楚时，当前手感与吃法匹配可到中高置信；只有颜色没有 `F` 时为低置信。油脂香、内部褐变、精确后熟天数这些看不到的事，别打包票。
